Skillbox — three design directions

Same product, same two screens (Library and Prompts), three complete visual languages. Everything is clickable: switches flip, the breaker cycles, search filters, tabs move between screens. Pick the one that feels right — or tell me what to steal from each.

Graphite

An instrument that sits next to Codex — monochrome, hairline, color only where state lives.

  • Rows carry a status dot, not a switch. Hover morphs the dot into a switch — one-click toggling without a wall of 51 orange controls.
  • System Prompts sit above Skills in the sidebar; selecting one gives the editor the full canvas.
  • Activation lives in the detail header — a slim 4-state pill beside the title, one caption line under it. No control card.
  • Delete is real and warned. Trash icon in the header → macOS-style confirm. Folders go to the Trash; symlinks remove the link only.

Atelier

A craftsman's bench at night — warm charcoal, serif titles, a spine on whatever you've pulled off the shelf.

  • Switches stay visible on every row — this is the "see everything, flip anything" direction — but smaller, sage-green when on, with off-rows dimmed.
  • Skill titles are set in New York serif. Skills are documents; the serif marks content, the sans marks chrome.
  • The selected row grows a terracotta spine that continues onto the detail card — one book pulled from the shelf.
  • The detail is a floating card, not a full-bleed pane — the desk shows around the paper.

Console

top for your agent's brain — an icon rail, a command bar, and a table you operate with the keyboard.

  • The 4-state control is the row. Click the breaker strip (ON · NAME · MAN · OFF) to cycle a skill's Claude state in place — no detail-pane round-trip.
  • One command bar owns search and filters. ⌘K focuses it; tool chips filter the table.
  • Names are monospace, times are tabular. Scanning 53 rows reads like a process list, on purpose.
  • The sidebar collapses to an icon rail — Library, Prompts, Settings. Maximum canvas for the data.

How to choose

A · GraphiteB · AtelierC · Console
Feels likeA Codex sibling — an instrumentIts own thing — a warm libraryA power tool — htop for skills
TogglingHover a row, flip the switchEvery switch always visibleClick the breaker to cycle 4 states inline
Visual riskLowest — disciplined monochromeSerif titles + warm paletteMonospace density; least "Mac-like"
Best whenYou live in Codex/Claude all day and want visual peaceYou want Skillbox to feel like a product, not a panelYou toggle constantly and want zero clicks wasted

My recommendation: Graphite chrome with the Atelier spine.

You named the Codex app as the bar twice — Graphite's discipline (dot-morph rows, quiet counts, hairlines) is what makes it feel silky rather than busy. But pure graphite risks reading as a Codex clone; stealing Atelier's one signature — the terracotta spine on the selected row and detail — gives Skillbox a recognizable fingerprint for nearly zero noise. Console's inline breaker is worth keeping as a power feature regardless: it can live in Graphite as the detail-pane control and as an option-click on any row's switch.
